# astronomy-progam


## 研究课题

### 4U 1626-67在新自转减速阶段的X射线观测研究

4U 1626-67 是具有超短轨道周期的吸积X射线脉冲星，其自转演化表现出多次由加速向减速转变的现象，为研究中子星磁层与吸积盘之间的相互作用提供了重要的观测对象。

2023年前后，该源再次进入自转减速阶段。本课题拟利用 CHandra X射线天文台在这一阶段获得的观测数据，对其展开系统的时变和能谱分析，尤其利用高分辨率光谱分析氧、氖等元素的发射线特征，并与历史观测结果进行比较，研究该天体在不同自转演化阶段的辐射性质以及吸积盘结构变化。



## 本仓库使用说明

`codespace`:
     文件夹存放项目相关代码，每次更新时请在子文件夹的README文件做好说明(目前为空，第一次更新的请自创一个README文件)

`data`: 该文件夹由 `astrodata` 和 `paper` 构成，分别是天文数据，参考文献，放东西进来也要写README说明用途等

`draft`: 是草稿，没完成的都可以丢里面，管理也是写README

`picture` : 专门存放图片共写的.md文件或其他用途调用，用来做图床
